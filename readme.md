# Ravanix Lite 1.2.0 🎉

We are pleased to announce the **first official GitHub release of Ravanix Lite** — a free WordPress plugin for creating, managing, and administering psychological questionnaires and assessments.

This release marks an important milestone in the development of Ravanix and the beginning of its public presence on GitHub.

## ✨ Highlights

* 🧠 Create and manage psychological questionnaires directly in WordPress
* 📝 Support for multiple question and answer types
* ⚙️ Flexible questionnaire configuration and scoring
* 📊 Automatic calculation of questionnaire scores
* 📈 Clear presentation of assessment results
* 💬 Automatic interpretation based on defined score ranges
* 🌐 Full support for RTL and Persian-language websites
* 📱 Responsive interface for desktop, tablet, and mobile devices
* 🔧 Designed to integrate naturally with the WordPress administration environment

## 🚀 Scoring & Interpretation

Ravanix Lite includes a flexible scoring engine that allows questionnaire results to be calculated automatically according to predefined scoring rules.

Interpretations can be associated with score ranges, allowing users to receive meaningful feedback based on their assessment results.

This architecture provides a foundation for implementing a wide range of psychological, personality, clinical, screening, and educational questionnaires.

## 🎨 User Experience

The plugin has been designed with simplicity and usability in mind, providing a modern and structured interface for both questionnaire administrators and participants.

Particular attention has been given to:

* Clean and intuitive administration
* Responsive questionnaire presentation
* RTL compatibility
* Consistent WordPress integration
* Clear result presentation

## 🔮 Ravanix Pro

Ravanix Lite provides the core foundation of the Ravanix assessment platform.

The **Ravanix Pro** edition is being developed for professionals and organizations requiring more advanced psychometric and reporting capabilities, including advanced norms, composite factors, professional reports, PDF generation, import/export capabilities, and additional assessment features.

## 📦 Installation

Download the release package and install it through:

**WordPress → Plugins → Add New → Upload Plugin**

After installation, activate **Ravanix Lite** from the WordPress Plugins page.
